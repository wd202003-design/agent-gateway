# 安全模型与验证

Agent 进程、模型输出、外部网页、仓库代码和工具返回均视为不可信输入。

## 控制要求
- 身份：可信认证、租户绑定、跨租户访问拒绝。
- 授权：策略决策与执行分离，在工具代理和资源侧强制执行。
- 凭据：平台托管、短期最小权限令牌，Agent 子进程环境清洗。
- 隔离：非特权身份、资源限制、受控网络、最小 Linux capabilities。
- 审计：记录主体、任务、策略版本、调用、决策和结果；敏感信息脱敏。
- 故障：策略组件不可用时，高风险操作默认拒绝。

## 验证探针
- P1：沙箱非特权用户、metadata 回读、pause/resume。
- P2：执行器降权、env 清洗与凭据不可见性。
- P3：只读根、hidepid、xattr、原子重命名。
- P4：Agent 能否直连宿主机或 loopback 工具端点。
- P5：pause/resume 对进程、TCP、落盘数据的保留语义。
- P6：跨租户文件、网络、任务和制品访问拒绝。
- P7：Worker 失联、租约过期、重复执行和 fencing。

每个探针需记录版本、环境、步骤、预期、实际结果与证据。未验证不得宣称安全保障已生效。
