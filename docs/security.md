# 安全与审计基线

- SK 只存不可逆校验值或受保护引用，支持轮换、撤销、作用域和租户限额；禁止明文记录。
- 上游凭据仅由可信数据面凭据管理组件读取，控制面配置须加密并审计。
- 防止 SSRF、越权模型访问、跨租户账单查询、日志泄露和任意 endpoint 注入。
- 管理 API 与推理 API 分离权限；价格、渠道凭据、路由策略变更需审批/审计。
- 日志默认不保存 prompt/response 正文，按租户策略启用受控采样与脱敏。
- 计费事件需包含唯一 request_id、tenant_id、key_id（非明文）、model、channel、用量、成本及价格版本；异步投递采用幂等去重与对账。
- 明确请求在超时、断连、流式中断、上游缺失 usage 时的估算/补偿规则。
- 对控制面失联、渠道失效、凭据轮换和事件总线积压进行故障演练。
